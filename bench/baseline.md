# Baseline — fitted per-invoke cost model (M1.6 snapshot)

Generated by `bench/run.mjs` (tiers 1–2) per `docs/evaluation.md`.
Every number below is reproducible with `node bench/run.mjs`. This
snapshot **supersedes the v1.5 baseline**: the runtime changed shape
(authority-handle split, clone-before-policy, type-tagged canonical
domain), and the protocol changed to per-replicate pairing.

The "no journal" side of every pair is the explicitly **non-conforming**
`bench: true` sink (constant-time hashing; events are still generated),
not a removed journal. All paired variants run the identical mediated
workload, instantiated in the same round.

### Paired deltas (per-replicate, same round index)

| pair | Δmean | Δmedian | ratio (journal / no-journal) |
|---|---|---|---|
| `cap_journal` − `cap_bench` | **+9 794** | +9 843 | **3.29×** |
| `tool_loop_journal` − `tool_loop_bench` | +7 780 | +8 204 | 2.09× |

### Fitted coefficients

```
c_cap     ≈ 4.3 µs    mediation floor (clone + WeakMap + plumbing, no crypto)
c_journal ≈ 9.8 µs    audit path per mediated invoke (paired Δmean)
c_mem     ≈ 0         (per membrane; ≤ 0.3 µs, inside run-to-run noise)
c_ipc     ≈ 7.8 µs    mediated tell+recv roundtrip, journaling on
c_derive  ≈ 6.8 µs    grant step with consent + occupancy check, journaling on
memory    ≈ 1 018 B   journal retained per mediated invoke (deep-size
                      estimate of journalEntries(), not process RSS)
```

**v1.6 mediation costs ~1.56× v1.5** (cap_journal median 9 018 → 13 970).
The increase is not drift — it is the in-realm price of what the re-audit
demanded: args are cloned before membranes (was: shared references),
results clone-or-fail (was: shared-reference fallback), the canonical
serializer is type-tagged and cross-realm-safe (was: sentinel strings),
and every privileged call does a WeakMap handle-classification. The
audit share of a mediated invoke is
f = 9 794 / 14 078 ≈ **0.70** (v1.5: 0.72) — crypto still dominates,
the *split* between audit and mediation held nearly perfect while both
terms grew.

## Amdahl before optimizing (charter §4)

Paired measurement on the mediated invoke: audit share f ≈ **0.70**.

- 2× faster digest: `1 / ((1−0.70) + 0.70/2) ≈ 1.54×` end-to-end.
- Complete elimination of audit crypto: upper bound `1/(1−0.70) ≈ 3.3×`.
- Halving the mediation floor (4.3 µs of the 14.1 µs): ≤ 1.20× — not
  worth any security loss.

Priority stands: attack the hash path first —
1. **batch the chain hash** (one digest over k events; per-batch tamper
   evidence, weakens per-event chaining — needs an invariant #10 wording
   check before adoption);
2. stream `argsHash`/`resultHash` only when a consumer is attached;
3. leave membranes alone — measured free at n ≤ 3, twice now.

## M5 implications (enforcement-backend decision)

- v1.6 overhead is still crypto-dominated (~70% of a mediated call), so
  a kernel backend cannot win on this axis unless it changes *where* and
  *how often* hashing happens. Judge backends on isolation properties
  (#5, #7, #8) and re-measure at tier 3 (charter §2: microkernel numbers
  may not justify a backend decision — stated explicitly per the
  "benchmarks always valid" fallacy).
- The queue-only floor (~1.2 µs/op with clone + mediation, no crypto)
  says what semantic work costs before any transport: M3 worker/child
  transports add serialization + syscall cost on top, and that delta is
  the honest transport-budget question. Do **not** extrapolate these µs
  figures to a kernel ABI.

## Caveats (charter §3 honesty clause)

- Measured in an embedded Node REPL (single process, warm JIT, noisy
  shared laptop). No standalone `node.exe` was available in this
  environment, so "Node v24.18.0 (embedded-REPL harness)" is the runtime
  of record; a `node bench/run.mjs` run on a clean install is the
  reproduction path and may shift means by ~±15%. Per-replicate spread is
  wide (e.g. `cap_journal` min 12 274 / max 16 196) — co-tenant load,
  not variant logic; conclusions ride on *paired same-round deltas*, not
  absolutes.
- The two pairs disagree on audit share (3.29× vs 2.09) because their
  no-crypto baselines differ by an attached membrane and cache
  placement. The honest reading: the audit path costs ~8–10 µs per
  mediated invoke and any claim tighter than that needs tier-3
  hardware.
- Cooperative timing: microtask granularity inflates the `raw` floor.
- Memory is a deep-size estimate over `journalEntries()` snapshots
  (64 B/object header assumption); it excludes retained cap/actor
  graphs and V8 fragmentation.
